# MindEase – Mental Wellness Web Application

## About the Project
MindEase is a web-based mental wellness application developed to help users monitor and maintain their mental well-being through various interactive features and wellness resources.

This project was developed as a group project, with equal contributions from all team members.

## Features
- User Registration and Login
- Mood Journaling
- Medication Tracking
- Progress Monitoring
- Daily Motivational Quotes
- Psychologist Information
- Mental Health Helpline Information
- Interactive Mind Games

## Technologies Used
**Frontend:** React.js, HTML, CSS, JavaScript

**Backend:** Node.js, Express.js

**Database:** MongoDB, Mongoose

**Libraries:** Axios, React Router

## My Contribution

## Installation and Setup
1. Clone the repository.
2. Install the required dependencies in the frontend and backend folders.
3. Configure the MongoDB connection and environment variables.
4. Start the backend and frontend servers.

Refer to the respective package.json files for available scripts.
